# All You Need to Know About dLLMs — interactive tutorial design

Date: 2026-07-07. Status: approved.

## What this is

A standalone interactive web tutorial on diffusion language models, curated
from the 90-page LaTeX tutorial "The Past and Present of Text Diffusion
Models" (v2, source of truth for all claims and numbers). English only.
Deployed as a static site to GitHub Pages.

Scope rule: the dLLM story in full (anchor, masked diffusion core, decoding,
block dial, families, post-training, serving, safety, cheat sheet); the
continuous-diffusion derivation chain (DDPM/score/FM math) compressed to
interactive intuition with pointers to the PDF companion.

## Stack

- Astro (static output) + Svelte islands for widgets.
- MDX content, KaTeX rendered at build time (remark-math + rehype-katex).
- No server; all widget data is static JSON committed to the repo.
- GitHub Actions workflow (`withastro/action`) deploys to Pages.

Rejected: SvelteKit static (prose pages gain nothing from being components);
Vite SPA (wrong shape for a content site: deep links, load, print).

## Pages (hub + 9 chapters)

0. Hub — hero, the anchor sentence, family-tree teaser, chapter cards.
1. Two Ways to Write a Sentence — AR vs diffusion anchor; auto-playing
   decoding teaser.
2. How Masked Diffusion Works — masking process, weighted cross-entropy
   objective, any-order identity; collapsible derivations.
3. Where dLLMs Came From — interactive timeline (prehistory -> D3PM -> MDLM
   -> LLaDA/Dream; flow matching as the parallel road).
4. The Decoding Playground — trajectory replay widget (policy switcher,
   NFE slider) + measured NFE/quality/latency explorer + judge-gaming toggle.
5. The Block Dial — B slider morphing the attention-mask grid, marker on the
   real BD3-LM perplexity curves; KV-cache story.
6. The Family Atlas — clickable family tree, per-family identity cards, the
   four axes, "read off the coordinates" quiz.
7. Making Them Useful — scaling-law phase diagram, post-training/RL, serving,
   break-even calculator.
8. Safety When Decoding Is Parallel — mask-infilling attack step-through,
   defenses, honest caveats.
9. The Cheat Sheet — twelve numbers, decision helper, annotated further
   reading with arXiv links.

## Widgets (Svelte islands)

1. `DecodingPlayground` — replays REAL step-by-step canvases exported from
   the trained 1.85M tiny MDLM (no scripted animation). Controls: policy
   (confidence / noisy / random), NFE (4/8/16/32/64), step scrubber,
   auto-play. Data: `traj_*.json` produced by a new `export_traj.py` in the
   LaTeX repo's `code/`, copied here.
2. `BlockDial` — slider B in {1,4,8,16,...,L}; draws the block-causal
   attention mask on a canvas grid; marker interpolates along measured
   BD3-LM LM1B/OWT curves (constants from the paper's Tables 3-4, already
   verified). Labels bounds with "<=".
3. `FamilyAtlas` — tree layout (state space -> granularity -> provenance),
   click a family for its identity card; quiz mode presents a model spec and
   asks for its coordinates (Dream, SSD-LM, BD3-LM at B=1, TESS-2, Duo).
4. `NfeExplorer` — measured curves from `sampling.json` (genPPL per policy,
   wall-clock, AR references); judge-gaming toggle showing AR-self 2.8 vs
   real text 5.5.
5. `BreakEvenCalc` — small form (L, N, cache regime) computing the serving
   arithmetic from the tutorial's break-even model.

## Data flow

`assets/data/` holds: `sampling.json` (copied from toy run), `trajectories/`
(new export), `bd3lm.json` (table constants + citation), `families.json`
(identity cards), `timeline.json`, `numbers.json` (cheat-sheet twelve).
Widgets import JSON statically; no fetch at runtime except same-origin JSON.

## Content and style rules

- Every number traces to the verified sources in the LaTeX tutorial; cite as
  numbered hover links to arXiv.
- House palette: indigo #2B4C93, teal #0F7B6C, plum #6A4A8E, amber #B5730B,
  rose #B23A5B accents; serif prose (Charter/Georgia stack), sans headings.
- Date labels neutral ("As of July 2026"). No generator footers, no tooling
  self-reference in rendered output. Credit line points to the PDF companion.
- Callout boxes mirror the PDF: key idea, intuition, where-this-might-be-wrong.

## Testing / acceptance

- `npm run build` exits 0 with zero broken internal links (Astro checks) and
  all JSON parse at build time.
- A `scripts/check.mjs` validates: every chapter page exists, every widget's
  data file parses, no page contains banned strings ("Generated by",
  "skill", em-dash character).
- Visual pass: each page rendered and inspected before deploy.
- Deploy: workflow committed; actual push + Pages enablement only on user
  go-ahead.
