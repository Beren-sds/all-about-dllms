# All You Need to Know About dLLMs — Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** A static, interactive web tutorial on diffusion LLMs (hub + 9 chapters, 5 data-driven widgets), curated from the v2 LaTeX tutorial and deployable to GitHub Pages.

**Architecture:** Astro static site with MDX chapter pages (KaTeX math rendered at build time) and Svelte islands for the five widgets. All widget data is static JSON committed to the repo; real numbers come from the LaTeX tutorial's verified sources and the tiny-dLLM run logs. No server, no runtime fetch beyond same-origin JSON imports resolved at build.

**Tech Stack:** Astro 5, @astrojs/svelte (Svelte 5), @astrojs/mdx, remark-math + rehype-katex, plain CSS (no framework). Node 22.

**Source of truth for content:** `~/Desktop/ObsidianVault/wiki/tutorials/text-diffusion-models/` (sections/*.tex, refs.bib, code/runs/*.json). Every number cited in a page must exist there.

**Global content rules (checked by `scripts/check.mjs`):**
- No em-dash characters anywhere in rendered output.
- No "Generated by", no tooling/skill self-reference.
- Date labels: "As of July 2026".
- Banned words in prose: leverage, unlock, unified, synthesis, lens, insight.
